# Social icons

Official brand icons used for the social buttons in the footer and on the home page (resized copies from each company's brand resources):

- `facebook.png`
- `instagram.png`
- `youtube.png`

To swap one, save the new file with the same name in this folder (about 160 px tall works well), then commit and push.
Names and links are set in `SOCIAL_LINKS` at the top of `js/nav.js`. If an icon file is missing, that button falls back to its text label.
